# 韵农甄选 × 京东货盘(来一票)—— 全流程说明(给老板看)

> 一句话:**我们的商城负责「卖」和「收钱」,京东负责「发货」。** 顾客在我们这里付款,我们再用在来一票的**预存款**向京东买这件货,京东直接发给顾客。差价就是我们的毛利。

## 全流程(谁做什么、钱怎么走、代码里由什么触发)

### ① 选品导入 —— 我们(管理员)
- **做什么**:后台「京东货盘 → 选品」按分类/关键词浏览来一票商品池,点「导入」。
- **系统自动把关**:只允许经营范围内的类目(新鲜水果/蔬菜/鲜蛋、数码配件、电脑配件、网络设备等);预包装食品(大米、杂粮等)、整机、药品等按规则**禁售不导入**;商品标题里有「最」「第一」等广告法违禁词的进「待审核」不上架。
- **退货规则完全按接口**:每个商品按京东返回的规则显示「支持/不支持 7 天无理由退货」,不支持的商品,顾客下单前必须勾选「我已知晓」。
- **代码**:`browse()` 选品浏览 → `importSku()` 导入(调用 searchGoodsDetail / getSellPrice / checkSkuSaleList 等**只读查询接口,不花钱**)。
- **钱**:不涉及。

### ② 定价 —— 系统自动(规则由我们定)
- **规则**(后台可改):默认 **售价 = max(京东标价, 成本价 × (1 + 加价率))**,加价率默认 10%;也可改为「成本 + 加价」模式。
- **自动更新**:每 6 小时自动刷新一次价格和可售状态(`refreshProducts()`);京东推送「价格变动/下架」消息时立即刷新。成本涨了售价跟着涨;京东下架则我们自动下架。
- **钱**:成本价 = 我们付给京东的钱;售价 − 成本 = 毛利。

### ③ 展示 —— 系统自动
- 商品在首页「全部商品」、分类页显示,标注「由供应商发货」、对应的退货规则、运费。
- 顾客每次结算前,系统**实时**向京东核对:该地址能不能送(checkArea / checkAreaLimitList)、最新成本价(getSellPrice)、运费(querySkuFreight)。价格变了会提示顾客,不能送的不让下单。

### ④ 顾客下单 —— 顾客
- 选商品 → 填收货地址 → 确认订单(`/checkout` → `/order/create`)。此时只生成我们自己的订单,**还没有向京东下单**,也没有扣任何钱。超时不付款自动取消。

### ⑤ 微信付款 —— 顾客 → 我们的商户号
- **钱**:顾客付的钱进**我们自己的微信商户号**(京东拿不到这笔钱)。
- **现状**:微信支付尚未接入,演示站是「模拟支付」(`/order/:id/pay`)。
- **代码**:付款成功 → `payOrder` → `onPaid()` 登记一条「待向京东下单」记录。

### ⑥ 系统向京东下单,扣预存款 —— 系统(现阶段由管理员手动触发)
- **正式运行时(自动)**:付款成功后系统自动执行(`kick()` / 每分钟定时任务 `tick()` → `processOrder()`):
  1. 再查一次最新成本价,**成本价高于顾客实付价就不下单**并自动退款给顾客(避免亏本);
  2. `submitOrder` 预下单 —— **此时从来一票预存款里扣钱**(扣成本价 + 京东运费);
  3. `confirmOrder` 确认订单 —— 确认后京东才发货。
  失败会自动重试(最多 3 次);最终失败则取消京东预下单(退回预存款)并给顾客全额退款,同时后台告警。
- **现阶段(测试期)**:自动下单关闭。管理员在后台订单页点 **「向京东下单(扣预存款)」**,并输入该订单号确认,才会对这一笔下单;单笔金额默认上限 ¥300。
  - 开启方法(需要时再开):演示站环境变量 `JDVOP_ORDER_ENABLED=1`,阿里云中转 `RELAY_ALLOW_ORDERS=1`。两处都开才会真正下单。
  - 正式开张后要改成自动:`JDVOP_SUBMIT_ORDERS=1`,并且不能是演示模式(`DEMO_MODE` 不为 1)。
- **钱**:预存款 −(成本价 + 运费)。

### ⑦ 发货 / 物流回传 —— 京东发货,系统自动同步
- 京东拆单、发货后,通过**回调**(`/api/suppliers/jdvop/callback` → `handleCallback()`)通知我们;另有每 10 分钟的**轮询兜底**(`poll()` → `syncOrder()` 调 getOrderDetail / queryDeliveryInfo)。
- 系统自动把运单号、物流公司、包裹写进订单,订单变为「已发货」,顾客在「我的订单」里看物流。我们**不需要人工发货**(后台也禁止对京东商品手动发货)。

### ⑧ 确认收货 —— 顾客(或系统自动)
- 顾客点「确认收货」;不点的话签收后 7 天自动确认收货。京东的签收状态也会同步过来。
- **钱**:正式接入微信支付后,确认收货后这笔交易才算完成(结算周期以微信商户号规则为准)。

### ⑨ 售后 / 退款
- **顾客**在订单里申请售后(退货/换货/仅退款,按该商品的退货规则)。
- **我们(管理员)**审核后,在订单页点「为供应商商品申请售后」把申请提交给京东(`createAfs`);京东审核,需要退货的,顾客把货寄回京东指定地址并填写运单号(`updateSendInfo`)。
- **京东退款到我们的预存款** → 系统查询确认京东「退款成功」后(回调 + 轮询,`syncAftersale()`),才**自动给顾客原路退款**(`refundOrder`)。先确认京东退了,再退顾客,避免我们垫钱。
- 未发货前取消:京东单可取消(`cancelOrder`),预存款退回,顾客全额退款。
- **钱**:京东 → 预存款(退成本);我们的商户号 → 顾客(退售价)。

## 钱的流向汇总
```
顾客 ──付售价──▶ 我们的微信商户号(收入)
我们的来一票预存款 ──扣成本价+运费──▶ 京东(下单时)
毛利 = 售价 − 成本价 − 运费 − 微信手续费
售后:京东 ──退成本──▶ 预存款;我们 ──退售价──▶ 顾客
```
后台「京东货盘 → 对账」页按订单列出:顾客实付、京东扣款、双方退款、毛利。预存款余额在后台可查,余额不足下单会失败并告警,需要提前充值。

## 正式开张前还要做的
1. 接入真实微信支付(商户号、支付回调、真实退款)。
2. 用一笔真实测试单走完 ⑥~⑨(手动下单 → 发货 → 签收 → 可选:售后退款),核对预存款扣款与对账页一致。
3. 演示站目前用 HTTP 连中转;开放下单(含顾客收货地址)前,给中转加域名 + HTTPS。
4. 正式站换成付费数据库/服务器(免费版每次更新会清空数据)。
5. 确认无误后,打开自动下单(`JDVOP_SUBMIT_ORDERS=1`,非演示模式)。
