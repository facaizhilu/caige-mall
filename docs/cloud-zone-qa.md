# 云商专区实现与验收边界

## 业务与权限

- 唯一公开入口为「云商卡」页的绿色体验按钮，手机号由底部弹层输入；不在其他前台页面添加专区入口。
- 必须登录，只比较当前账号绑定号码；陌生号码与其他账号号码统一返回本账号号码提示，不查询或披露他人会员资格。
- 后台会员列表和会员详情有「云商专区资格」开关，新账号默认关闭。一次性迁移仅为现有有效云商卡会员开启资格；不会重复迁移或自动覆盖后续人工关闭。演示环境（`DEMO_MODE=1`）启动时仅为专用测试号 `13800000001` 自动开通专区资格，其他演示账号仍须后台开启；正式环境未设置该变量时不会自动开通。演示站重启会再次为该测试号打开资格，同一次运行中后台关闭仍立即生效。
- 专区资格独立于原有卡档位、有效期、普通商城折扣和签到规则；不改这些既有权益。原卡开通/续期同步开启专区，停用同步关闭。可单独关闭专区而保留原卡权益。
- 授权仅存服务端会话，绑定用户、手机号摘要和资格版本，有效期30分钟。关闭、重新打开资格、换号或注销均使原授权失效。退出后须重新验证。
- 每账号10分钟最多5次失败尝试，计数保存在数据库。专区页、商品页、报价、创建订单、付款均再次检查实时资格；不接受客户端提交的伪造授权。
- 关闭资格后仍能查看本人历史订单、售后和退款记录，不剥夺已购商品权益。

## 商品与价格

- 后台独立「云商专区商品」维护商品、售价、库存、图片、文字详情、分类、运费模板、七天无理由规则及上下架。已有订单的商品只允许下架，不允许删除。
- 数据迁移和启动不创建专区商品，当前按要求留空；不投放假商品。
- 普通首页、分类、搜索、详情、推荐、收藏、足迹、购物车、秒杀/拼团及活动SKU选项不包含专区商品，普通商品预览和伪造加购也不能绕过。
- 专区按后台自定义售价结算，不叠加普通会员折扣、优惠券或积分抵扣；运费仍按所选运费模板及既有包邮规则。禁止与普通商品混单。
- 服务器校验分类经营范围、名称及敏感表述、售价大于0且不超过20000元、库存整数、有效运费模板、图片URL。软件校验不替代运营对商品资质、实物、定价、宣传及售后规则的人工合规复核。

## 视觉与部署核对

- 本地合成页面核对320、375、430宽度的卡面、底部弹层、错误提示及空专区；不代表线上真实账号操作证据。
- 末轮三宽核对绿色渐变专区页头、空箱图标、关闭弹层后清空号码和错误均通过。商品页移除旧价格伪元素导致的多余货币符号，并采用独立固定购买栏、隐藏该页主导航；320/375/430均完整显示按钮，规格/数量/详情可滚动至购买栏上方。430宽、985高视口的按钮为402×44，距底部8px。
- 普通商城其他页面原有会员价/卡档位金色保留；本次卡面、体验按钮、弹层和专区页面使用绿色，不改全站其他已批准配色。
- 发布后核对公开页面、受保护专区的未登录跳转及 `X-App-Revision`。正式环境短信验证、微信真实支付退款、小程序和合规审查不在此次模拟测试完成范围。
